# 云开发部署手册

> 这是**当前方案**的详细部署步骤（[PLAN.md](PLAN.md) Phase 0 的展开版）。
> 目标：小程序 + 云开发，不买域名、不备案、不用服务器，部署完停在**体验版**。

从零到能用，大约 **20 分钟**。每一步都给了「怎么验证这一步成功了」。

---

## 0. 前置条件

| 项 | 要求 | 说明 |
| --- | --- | --- |
| 微信开发者工具 | 稳定版 ≥ 1.06 | [下载](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) |
| 小程序 AppID | 已注册的小程序 | **云开发必须用真实 AppID**，测试号/游客模式不行 |
| 基础库 | ≥ 2.17.1 | 用到了 `wx.showModal({editable})`、`wx.shareFileMessage` |
| Node.js | ≥ 16（仅本地跑测试用） | 部署云函数时由云端安装依赖，本机不需要 npm install |

> 个人主体也能注册小程序并开通云开发。本项目是私人记录工具，不需要企业资质。
> 注意：**个人主体不要选「医疗健康」类目**，我们这个不是医疗产品。

---

## 1. 注册小程序，拿到 AppID

1. 打开 <https://mp.weixin.qq.com> → 立即注册 → 小程序。
2. 邮箱激活 → 补充主体信息（个人：身份证 + 微信扫码）。
3. 进入后台 → 「开发」→「开发管理」→「开发设置」，复制 **AppID**。

**验证**：后台能看到 AppID（形如 `wx1234567890abcdef`）。

---

## 2. 导入项目

1. 微信开发者工具 → 「导入项目」。
2. 目录选择**本仓库根目录**（含 `project.config.json` 的那一层）。
3. AppID 填上一步的 AppID。
4. 后端服务选择「不使用云服务」也没关系，下一步在工具栏开通。

**验证**：项目能打开，模拟器里出现首页（此时点按钮会提示还没连上云端，属正常）。

---

## 3. 开通云开发，填环境 ID

1. 工具栏点「云开发」→ 开通（首次会让你选套餐，按量付费/包月，个人用最低档即可）。
2. 创建一个环境，名称随意（如 `babycare`）。
3. 复制**环境 ID**（形如 `babycare-7g8h9i0j`）。
4. 打开 [`miniprogram/config.js`](../miniprogram/config.js)，填入：

```js
module.exports = {
  ENV_ID: 'babycare-7g8h9i0j',   // ← 改这里
  ...
}
```

**验证**：配置文件里不再是空字符串。留空时会尝试使用账号默认环境，多环境情况下容易连错，建议显式填写。

---

## 4. 部署云函数

对 `cloudfunctions/` 下两个目录各做一次：

1. 在开发者工具左侧文件树里，**右键** [`cloudfunctions/api`](../cloudfunctions/api) → **上传并部署：云端安装依赖（不上传 node_modules）**。
2. 等待右下角提示「上传成功」。
3. 同样操作 [`cloudfunctions/backup`](../cloudfunctions/backup)。

然后配置定时触发器：

4. 右键 [`cloudfunctions/backup`](../cloudfunctions/backup) → **上传触发器**。
   （`config.json` 里已写好：`0 30 3 * * * *`，即每天 03:30 执行。）

**验证**：云开发控制台 → 云函数，能看到 `api` 和 `backup` 两个函数；`backup` 的「触发器」里有 `dailySnapshot`。

---

## 5. 创建集合与权限（关键，别跳过）

集合会在第一次调用时自动创建（`ensureCollections()`），但**权限必须手动设**，否则数据对客户端敞开。

1. 回到模拟器，编译后首次打开首页，云函数会自动建好 `users` / `families` / `records` / `backups`。
   - 如果首页报错，也可在云开发控制台 → 数据库 → 手动「新建集合」，四个都建。
2. 对**每一个**集合：数据库 → 点集合名 → 「权限设置」→ 选 **仅管理端可读写**。
   （若界面是自定义安全规则，把读、写都设为 `false`。）
3. 建议顺手加索引（数据量大一点更稳）：

| 集合 | 索引字段 | 类型 |
| --- | --- | --- |
| `records` | `familyId`(升序) + `updatedAt`(升序) | 组合，非唯一 |
| `records` | `familyId`(升序) + `startAt`(升序) | 组合，非唯一 |
| `families` | `inviteCode` | 单字段，唯一 |
| `users` | `openid` | 单字段，唯一 |

**验证**：在「数据库 → records」里用「添加记录」手动加一条，然后在小程序里下拉刷新——看不到它（因为权限和 familyId 都不匹配）是正常的；把权限改回开放再试则会看到，说明权限生效了（试完记得改回来）。

---

## 6. 调整云函数超时（重要）

默认超时时间很短，全量同步几千条记录或导出 CSV 时会被掐断。

云开发控制台 → 云函数 → `api` → 「版本与配置」/「配置」：

| 配置 | 建议值 |
| --- | --- |
| 超时时间 | **20 秒** |
| 内存 | 256 MB |
| 环境变量 | 不需要 |

`backup` 也建议设为 60 秒（要遍历所有家庭组）。

**验证**：随便记录几条数据，然后在设置页点「导出 CSV」，能正常生成。

---

## 7. 跑起来：第一次记录

1. 点「编译」。
2. 首页应显示日期、「我的家庭」、「开始睡觉」。
3. 点「开始睡觉」→ 卡片变成「已睡 0分 / 醒了」。
4. 等 30 秒，数字自动增长（页面每 30 秒刷新一次进行中的计时）。
5. 点「醒了」→ 记录出现在「最近记录」。

**验证数据真的进云了**：

- 云开发控制台 → 数据库 → `records`，应看到一条 `type: "sleep"` 的文档，带 `familyId`、`createdAt`、`updatedAt`。
- `families` 里有一条家庭组，`inviteCode` 是 6 位。

---

## 8. 家庭共享（两个人一起用）

1. 妈妈手机：设置页 → 「邀请码」→ 点一下复制。
2. 爸爸手机：用同一小程序（体验版/正式版）打开 → 设置页 → 输入邀请码 → 「加入」。
3. 加入后爸爸会立刻拉到已有记录；之后任意一方新增，另一方在切回首页时自动同步。

**注意**：如果爸爸之前自己记过数据（系统自动给他建了一个家庭组），加入时会把那些记录**自动迁移**到妈妈的家庭组（前提是那个家庭组只有他一个人）。若已有多人，则不做迁移，但请放心——数据仍在云端，不会删。

**验证**：爸爸机上记一条喂奶，妈妈机下拉刷新，能在「最近记录」里看到。

## 9. 真机与发布

### 9.1 真机预览

点工具栏「预览」→ 手机扫码。**云开发在真机上同样可用**，无需额外配置域名。

### 9.2 体验版（给家人用，不公开）

1. 工具栏「上传」→ 填版本号（如 `1.0.0`）。
2. 微信公众平台 → 「管理」→「版本管理」→ 找到刚上传的版本 → 「选为体验版」。
3. 「成员管理」→ 把家人的微信号加为**体验成员**。
4. 家人扫体验版二维码即可长期使用。

> 家庭自用强烈建议停在**体验版**：不经过审核、随时更新、只有自己人能进。

### 9.3 正式发布（本方案不需要）

> ⚠️ **当前方案（[PLAN.md](PLAN.md)）明确不发布。** 一旦点「发布」，云开发免费环境会在 15 天后转付费。
> 下面内容仅当你将来改变主意、要做公开产品时参考。

1. 公众平台 → 「设置」→「基本设置」→ 服务类目：选 **工具 → 效率**（或「工具 → 信息查询」）。
2. 「设置」→「服务内容声明」→ **用户隐私保护指引**：声明使用微信账号标识（openid）用于区分家庭成员，不收集手机号、位置、通讯录。
3. 「版本管理」→ 提交审核 → 填写功能页面与测试说明（说明这是私人记录工具，所有数据存在用户自己的云开发环境）。
4. 审核通过后点「发布」。

**常见驳回原因**：类目与实际功能不符、隐私指引未填写、页面有明显未完成内容。按上面配置一般可以过。

## 10. 备份与恢复（请务必演练一次）

### 10.1 备份的三种方式

| 方式 | 操作 | 频率 |
| --- | --- | --- |
| 自动快照 | 无需操作，每天 03:30 写云存储 | 自动，保留 30 天 |
| 手动快照 | 设置页 →「立即生成云端快照」 | 大改数据前 |
| CSV 导出 | 设置页 →「导出 CSV（近 90 天）」→ 发送给文件传输助手 | 每月一次 |

快照文件位置：云开发控制台 → 存储 → `backups/YYYY-MM-DD/family-<id>-<时间戳>.json`。

### 10.2 恢复演练 A：单条记录误删

1. 云开发控制台 → 数据库 → `records` → 找到该文档。
2. 把 `deleted` 改为 `false`，`updatedAt` 改成**当前毫秒时间戳**（[在线取时间戳](https://tool.chinaz.com/Tools/unixtime.aspx)，或任意大于原值的时间）。
3. 在小程序里下拉刷新首页。

**为什么必须改 `updatedAt`**：客户端按 `updatedAt > lastSyncAt` 拉增量，不改时间的话各设备不会感知这次"复活"。

### 10.3 恢复演练 B：整表误删 / 数据错乱

以某天的快照为准恢复：

```bash
# 1. 从云开发控制台「存储」下载快照文件，例如 family-abc-1700000000.json
# 2. 把单个 JSON 对象转成 JSON Lines（云开发导入要求每行一个文档）
jq -c '.records[]' family-abc-1700000000.json > records.jsonl

# 3. 检查行数与内容
wc -l records.jsonl
head -c 300 records.jsonl
```

4. 云开发控制台 → 数据库 → `records` → 「导入」→ 选择 `records.jsonl`。
5. 冲突处理选 **「_id 冲突则覆盖」**。
6. 导入完成后，在手机上：设置页 →「清空本机缓存」→ 回首页等待重新全量拉取。

> 为什么第 6 步不能省：导入的文档 `updatedAt` 是历史值，客户端的增量游标已经越过它，不清缓存就拉不到"旧时间戳"的数据。

### 10.4 恢复演练 C：平台回档

云开发控制台 → 数据库 → 「回档」，选择时间点（按套餐提供，具体以控制台为准）。回档后再按 10.3 第 6 步清一次本机缓存。

### 10.5 真丢了怎么办（最坏情况）

如果云环境被误删，快照也在同一环境里一起没了——这就是为什么**必须定期导出 CSV 到微信外**。CSV 可用 Excel 打开，也能用脚本重新导入。

## 11. 排错表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 首页提示「还没连上云端」 | `ENV_ID` 没填 / 填错；`api` 未部署 | 检查 `miniprogram/config.js`；重新上传部署 `api` |
| 云函数日志报 `collection not exists` | 集合未建 | 调一次 `system.init`，或控制台手动建 4 个集合 |
| 报 `NO_OPENID` | 开发者工具未登录 / 游客模式 | 用真实 AppID + 登录微信后重新编译 |
| 报 `database permission denied` | 集合权限没设成「仅管理端可读写」 | 见第 5 步 |
| 记录能记但另一台手机看不到 | 两端不在同一家庭组 | 设置页核对邀请码 / 家庭名 |
| 一直显示「离线 · N 条待同步」 | 网络不通，或云函数报错 | 看云函数日志；数据在本机不会丢，修好后自动上传 |
| 导出 CSV 报超时 | 云函数超时太短 / 范围太大 | 第 6 步调到 20 秒 |
| 定时备份没生成 | 触发器没上传 | 右键 `backup` → 上传触发器；看 `backup` 日志 |
| 点瓶喂没反应 | 基础库过低（`showModal` 不支持 editable） | 后台把最低基础库设到 2.17.1 |
| 真机上 `wx.cloud` 不存在 | 基础库过低 | 同上 |

## 12. 迁移、卸载与交接

### 换一个云环境

1. 新建环境 → 改 `config.js` 的 `ENV_ID` → 重新部署两个云函数。
2. 把旧环境的 `records` 导出，导入新环境（同 10.3 的 JSON Lines 流程）。
3. 手机上清本机缓存 → 重新拉取。

### 把小程序交给别人

家庭组是数据边界。对方加入你的家庭组即可共享；如果要把整套数据给对方，导出 CSV 或快照 JSON 更合适。

### 彻底停用

1. 先导出 CSV 和快照。
2. 云开发控制台 → 环境 → 删除环境（**会清空所有数据和快照**）。
3. 公众平台 → 设置 → 注销小程序（可选）。

## 13. 本地开发与测试

```bash
npm test              # 全部 70 条测试
npm run test:stats    # 统计口径（23 条）
npm run test:store    # 同步引擎：离线写入 / 补传 / 多设备合并、分页（14 条）
npm run test:transport# 云函数分派与错误映射（6 条）
npm run test:api      # 云函数集成（27 条，内存版 wx-server-sdk 打桩）
```

改动统计逻辑后跑 `test:stats`；改动同步逻辑后跑 `test:store`；改动云函数后跑 `test:api`。这些测试都不需要微信开发者工具。
