# 低成本方案全景（2026-11 核实）

> 结论先行：**在"不备案"的前提下，能跑小程序的只有微信自家的两条路**（云开发 / 云托管）。
> 其他所有"免费后端"方案（Vercel、Cloudflare、Supabase、LeanCloud 国内版…）都会撞上备案这道墙。

---

## 0. 两条硬规则（决定了一切）

来自[小程序官方文档·网络](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)：

1. **服务器域名必须经过 ICP 备案**；不能是 IP 地址或 localhost；不支持配置父域名（要配子域名）。
2. **域名可以带端口**，例如 `https://myserver.com:8080`，但必须精确配置——配了带端口的，就只能请求带端口的那个 URL。

> ⚠️ 常见误传：「小程序不支持端口」。**错的**，端口支持，关键是必须备案 + 精确配置。
> 真正不支持的是 **IP 地址**，所以"自签证书 + `https://1.2.3.4:8443`"这种玩法对小程序无效。

唯一的例外写在同一份文档里：

> 「…作为后端服务，则可**无需配置通讯域名**（在小程序内通过 `callContainer` 和 `connectContainer` 通过微信私有协议向云托管服务发起 HTTPS 调用）」

这就是云开发和云托管能免备案的全部原因——它们走的是微信私有协议，不是 `wx.request`。

## 2. 逐个说清楚

### 2.1 云开发 + 不发布（¥0，免备案）★ 目前最优

[官方计费说明](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloud/billing/price.html)：

- 基础套餐 **¥19.9/月**（原价 ¥39，5 折长期有效），含 20 万次调用、2GB 容量、10 万 GBs。
- **免费体验**：2025-02-19 起，没有云环境的小程序账号可创建一个免费环境；
- **「免费云环境在小程序未发布上线阶段，无需开发者续费」**；
- **一旦发布上线**，免费环境到期时间改为「上线后第 15 天」，之后必须转付费。

推论：**家庭自用，永远停在体验版、不点"发布"，云环境就是 ¥0。**

- 配额：20 万次调用/月。按每天 50 次算，一个月 1500 次，用掉 0.75%。
- 风险：政策可能变（官方保留解释权）；体验版成员有数量上限但家庭够用；不适合需要正式发布的场景。

### 2.2 云开发 + 发布（¥19.9/月）

发布上线后就是 ¥19.9/月，一年 ¥239。适合"要正式上线、又不想碰服务器和备案"的人。

### 2.3 云托管（¥60–150/月）

免备案，但要跑容器。成本拆解（[官方刊例价](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloudrun/src/Billing/price.html)）：

| 项 | 刊例价 | 家庭用量估算 |
| --- | --- | --- |
| 容器 CPU | 0.055 元/(核·小时) | 0.25 核 × 730h ≈ ¥10 |
| 容器内存 | 0.032 元/(GB·小时) | 0.5GB × 730h ≈ ¥12 |
| **MySQL 算力** | **0.342 元/(个·小时)** | 每天 12 个活跃小时 ≈ ¥123 |
| 公网流量 | 0.8 元/GB | 只走 callContainer 不产生 |

首次赠送的免费额度**只有 3 个月有效期**，MySQL 那 720 小时只够跑一个月。

结论：对极低频的家庭应用，云托管是最贵的一档，不推荐。

### 2.4 自有服务器 + 备案域名（≈¥1/月）★ 长期最优

- 备案免费，但要域名（¥9–19 首年）+ 2–3 周等待。
- 服务器已有 → 边际成本 0。
- 代码现状即支持（`TRANSPORT: 'http'`）。

### 2.5 轻量应用服务器 + 备案（¥30/月）

腾讯云轻量 2C2G ¥35/月，包年 85 折 ≈ ¥357/年。阿里云同类促销常更低。适合"没有服务器"的人。

### 2.6 函数计算（FC / SCF）+ 备案域名

阿里云 FC、腾讯云 SCF 都有免费额度，按量计费，低频应用接近 ¥0。但：
- 要改造成函数形态（我们现在的 SQLite 单文件模式不适用）；
- HTTP 触发器的默认域名未备案，必须绑自己的备案域名；
- 冷启动延迟。

### 2.7 第三方 BaaS（LeanCloud / Bmob / 知晓云）

**国内版已经不再免备案了。** LeanCloud 官方 FAQ 明确：

> 「由于我们运营人员有限，我们无法协助开发版应用办理新增备案。建议…到 IaaS 服务商处自行完成备案和接入。」

也就是说这条路最终还是要你自己的备案域名，还多了一层第三方依赖。**不推荐。**

### 2.8 纯本地（¥0，无后端）

只存在 `wx.setStorageSync`。能满足"记录"，但换手机就没了、家人看不到。适合"只要自己用、且能定期导出"的极端场景。

### 2.9 网页版 PWA（¥0）

不是小程序，但走 H5 规则：不需要备案域名、不需要审核、微信里点链接就能用。本项目已实现。

### 2.10 境外 PaaS（Vercel / Cloudflare / Supabase / Firebase）

全部撞墙：小程序要求域名已 ICP 备案，而境外平台给的是 `*.vercel.app`、`*.workers.dev` 这类未备案域名，**无法配置为服务器域名**。

（除非你在它们前面挂一个已备案域名做反代——但那就等于你已经有备案域名了。）

## 3. 对本项目的推荐

按你的约束（极简应用、已有服务器、想零成本、家庭自用）：

| 优先级 | 方案 | 成本 | 动作 |
| --- | --- | --- | --- |
| **1** | 云开发 + 停在体验版 | **¥0** | 部署现成的 `cloudfunctions/`，不点发布 |
| **2** | 网页版 PWA | **¥0** | 已可用，今天就能记 |
| **3** | 备案 + 自有服务器 | ¥10/年 | 备案下来切 `TRANSPORT: 'http'` |
| 不推荐 | 云托管 | ¥60–150/月 | 除非备案彻底走不通且必须发布 |

## 4. 常见误区

| 说法 | 实情 |
| --- | --- |
| 「小程序不支持端口」 | 支持，但必须精确配置（`https://d.com:8080`） |
| 「用 IP 也能连」 | 不行，除局域网 IP |
| 「Cloudflare 有免费域名」 | 只有 `*.workers.dev` 子域，不是你的域名，不能备案 |
| 「用 BaaS 就不用备案」 | 国内 BaaS 已要求自有域名备案 |
| 「云开发一定免费」 | 只在**未发布上线**时免费，发布后 15 天转 ¥19.9/月 |
| 「云托管很便宜」 | 容器很便宜，MySQL 算力很贵 |
