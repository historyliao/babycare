# 实施方案（已决策）：云开发 + 体验版，不备案

> **决策日期**：2026-11-04（取代 2026-11-03 的「备案 + 自建」方案）
> **结论**：小程序只做**体验版**（不提交审核、不发布），后端用**微信云开发**（云函数 + 云数据库 + 云存储）。
> **不买域名、不备案、不用服务器**。
> **成本**：¥0/月（免费活动期内）；免费活动截止 **2026-12-31**，之后有 §7 的三条退路。

---

## 1. 为什么改成这个

| 方案 | 是否需要备案 | 月成本 | 结论 |
| --- | --- | --- | --- |
| **云开发 + 体验版** | 不需要 | **¥0** | ✅ 选定 |
| 备案 + 自建服务器 + 体验版 | 需要（2–3 周） | ≈¥0.8 | ⏸ 保留为退路，代码已就绪 |
| 云托管（`callContainer`） | 不需要 | ¥60–150 | ✗ MySQL 算力太贵 |
| 网页版 PWA | 不需要 | ¥0 | ✅ 保留，随时可用 |

选它的理由：

1. **零门槛**：不碰域名、备案、证书、服务器，今天就能跑起来。
2. **免备案**：云开发走微信私有通道，不受「服务器域名必须备案」约束。
3. **代码已经写好了**：`cloudfunctions/` 那套后端有 27 个测试，规则与自建版完全一致。
4. **体验版不会过期**（14 天/30 天限制的是「试用小程序」，不是体验版）。

代价（必须接受）：

- **免费窗口有限**：官方写明活动截止 2026-12-31。
- 数据在腾讯云，不在自己服务器上。
- 体验版只有体验成员能打开，不能被搜索、不能分享给外人。

## 2. 终态架构

```
   家人手机（体验版小程序）
            │  wx.cloud.callFunction（微信私有通道，不走域名）
            ▼
   ┌──────────────────────────────┐
   │ 微信云开发环境（免费）          │
   │  云函数 api  ── 家庭/记录/导出  │
   │  云函数 backup ─ 每日快照      │
   │  云数据库：users/families/     │
   │            records/backups    │
   │  云存储：backups/YYYY-MM-DD/   │
   └──────────────────────────────┘
```

- 小程序端：`TRANSPORT: 'cloud'` + `ENV_ID`
- 客户端仍有本地缓存与离线补传队列（断网可记）
- 快照双保险：定时触发器（若可用）+ 打开小程序时的兜底备份

## 3. 执行清单

### Phase 0 · 今天（约 20 分钟）：把环境搭起来

- [ ] 微信开发者工具导入项目，填自己的小程序 AppID
- [ ] 工具栏「云开发」→ 开通 → 创建环境（选免费）
- [ ] 复制**环境 ID** → 填进 [`miniprogram/config.js`](../miniprogram/config.js) 的 `ENV_ID`
- [ ] 右键 [`cloudfunctions/api`](../cloudfunctions/api) → **上传并部署：云端安装依赖**
- [ ] 右键 [`cloudfunctions/backup`](../cloudfunctions/backup) → 同样上传部署
- [ ] 右键 `backup` → **上传触发器**（免费环境可能不支持，不影响，见 §6）
- [ ] 编译运行，首页出现「开始睡觉」→ 点一下，能在云开发控制台的 `records` 里看到数据

**验收**：`cloudfunctions/api` 日志里有一次成功的 `family.bootstrap`；云数据库出现 `families`、`records`、`users` 三个集合。

> 集合会在首次调用时自动创建。创建后去「数据库 → 权限设置」把每个集合改成**仅管理端可读写**（默认的「仅创建者可读写」其实也安全，因为客户端从不直连数据库）。

### Phase 1 · 今天（约 30 分钟）：发给家人用

- [ ] 修改家庭名、走一遍完整流程（睡眠、亲喂、瓶喂、统计）
- [ ] 开发者工具「上传」→ 填版本号 `1.0.0`
- [ ] 公众平台 → 管理 → 版本管理 → 开发版本 → **「选为体验版」**
- [ ] 成员管理 → 添加家人微信号为**体验成员**
- [ ] 家人扫体验版二维码 → 输入邀请码加入同一家庭组

**验收**：家人手机能打开、能记录；两台设备数据互通（一台记，另一台切回首页能看到）。

> ⚠️ **绝对不要点「提交审核」和「发布」**。一旦发布，免费环境会在 15 天后转付费，而且需要过审。

### Phase 2 · 本周：把"数据不丢"验证一遍

- [ ] 设置页 →「立即生成云端快照」→ 云开发控制台「存储」里能看到 `backups/2026-11-xx/family-xxx.json`
- [ ] 关闭小程序再打开，确认兜底备份不会重复触发（`bc:lastBackupAt` 生效）
- [ ] 设置页 →「导出 CSV」→ 能发到微信文件传输助手
- [ ] 控制台把某条记录的 `deleted` 改回 `false`，客户端下拉刷新能拉回来

**验收**：快照、CSV、软删除恢复三条路都通。

### Phase 3 · 长期

- [ ] 每月：导一次 CSV 存到微信外
- [ ] 每月：看一眼云开发控制台的「存储」里有没有新快照
- [ ] 每季度：做一次恢复演练（见 [SELF-HOST.md §9](SELF-HOST.md)，逻辑通用）
- [ ] **2026-12 月初**：确认免费政策是否延期，按 §7 决策

## 4. 体验版备忘

| 事项 | 说明 |
| --- | --- |
| 会不会过期 | **不会**。一直有效，直到你上传新版本替换它 |
| 二维码 | 约 7 天失效，**重新生成即可**，版本本身不受影响 |
| 谁能打开 | 只有被加入的**体验成员**；非成员扫码会被拦，也搜不到 |
| 人数上限 | 个人主体约 15 人（家庭够用） |
| 更新版本 | 重新上传 → 再点「选为体验版」；家人重新打开即生效 |
| 不支持 | 支付、被搜索、分享给非成员——家庭记录都用不到 |

## 6. 数据不丢：四层 + 一道兜底

| 层 | 位置 | 触发 |
| --- | --- | --- |
| 主存储 | 云数据库 `records` | 每次记录即时写入 |
| 本机缓存 | `wx.setStorageSync` | 断网也能记，联网补传 |
| 云端快照 | 云存储 `backups/YYYY-MM-DD/*.json` | 定时器 03:30 **或** 打开小程序时兜底 |
| 离机留存 | CSV 导出 | 用户手动，每月一次 |

**为什么加兜底**：官方只写了"免费环境存在一些功能使用限制"，没说明定时触发器是否可用。所以 [`pages/home/index.js`](../miniprogram/pages/home/index.js) 里加了 `maybeBackup()`——距上次快照超过 20 小时就静默补一条。**只要家人每天打开一次小程序，快照就不会断。**

即使定时器和兜底都没跑成，还有本地缓存 + CSV。

## 7. 2026-12-31 之后怎么办

官方原文：「此活动时间截止到 2026 年 12 月 31 日，如有调整将提前 3 个月在微信开放社区及腾讯云官网进行通知。」

三种可能，对应三种动作：

| 情况 | 判断依据 | 动作 |
| --- | --- | --- |
| 活动延期 | 12 月前官方公告 | 什么都不用做，继续用 |
| 不延期，且你接受付费 | 控制台提示转付费 | 转基础套餐 ¥19.9/月（一年 ¥239） |
| 不延期，且不想付 | 同上 | **切自建**：买域名备案（¥10/年）→ 改 `TRANSPORT: 'http'` → 用 [SELF-HOST.md](SELF-HOST.md) 部署 |

**切自建的代价很低**：后端代码已写好并有测试，数据可以从云开发导出后经 `server/restore.js` 导入（转换脚本见 [SELF-HOST.md §13](SELF-HOST.md)）。切换只改 `config.js` 两行。

> 注意：云开发模式下，**网页版（`web/` + `server/`）和小程序不共享数据**，因为它们是两套后端。网页版只在切回自建后才有数据。

## 8. 风险与预案

| 风险 | 概率 | 预案 |
| --- | --- | --- |
| 免费活动不延期 | 中 | §7 三条路，切自建只改两行配置 |
| 免费环境定时器不可用 | 中 | 已加客户端兜底备份（每天首次打开补快照） |
| 体验版成员数不够 | 低 | 个人主体约 15 人，家庭够用 |
| 云开发环境被误删 | 低 | 环境删除会连云存储一起没 → 所以必须每月导出 CSV |
| 微信调整体验版政策 | 低 | 届时走审核发布即可，代码与后端都已就绪 |
| 手机丢失 / 换机 | — | 数据在云端，登录同一微信即可 |
