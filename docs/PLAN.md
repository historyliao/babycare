# 实施方案（已决策）：体验版 + 自建后端

> **决策日期**：2026-11-03
> **结论**：小程序只做**体验版**（不提交审核、不发布），后端跑在自己的服务器上，通过**已备案域名**的 HTTPS 接口通信。
> **成本**：域名 ¥9–19/年，服务器已有 → **¥0/月**。无月费、无云服务套餐、无审核。

---

## 1. 为什么选这个

| 候选 | 月成本 | 结论 |
| --- | --- | --- |
| **本方案：体验版 + 自建 + 备案域名** | **≈¥0** | ✅ 选定 |
| 云开发 + 体验版 | 免费到 2026-12-31，之后 ¥19.9 | ❌ 窗口只剩 2 个月，不能当长期方案 |
| 云托管（`callContainer`，免备案） | ¥60–150 | ❌ MySQL 算力太贵 |
| 网页版 PWA | ¥0 | ✅ 保留，作为备案期间的过渡 |
| 第三方 BaaS | 仍要备案 | ❌ 多一层依赖，无收益 |

关键事实（已核实）：

1. **备案只针对 API 域名，与"小程序是否发布"无关。** 服务器域名在「开发设置」里随时可配，不需要先发布。
2. **体验版本身没有过期时间**（14 天/30 天限制的是「试用小程序」，不是体验版）。
3. 因此：**不过审 + 不上架 + 数据在自己手里 + 每年一个域名钱** = 家庭自用的最优解。

## 2. 终态架构

```
   家人手机（体验版小程序）
            │  wx.request  https://baby.example.com
            ▼
   ┌─────────────────────────────┐
   │ 你的服务器                    │
   │  Caddy（自动 HTTPS/证书续期）  │
   │    └─ Node 服务 :3000        │
   │         └─ SQLite 单文件      │
   └──────────────┬──────────────┘
                  │ 每天 03:30
                  ▼
        阿里云 OSS 快照（保留 30 天）
```

- 小程序端：`TRANSPORT: 'http'` + `API_BASE: 'https://baby.example.com'`
- 无 npm 依赖，迁移 = 复制文件
- 断网时小程序端仍有本地缓存与补传队列

## 3. 执行清单

### Phase 0 · 今天（1 小时）：本地跑通，先能用

- [ ] 服务器上启动服务
      ```bash
      cd /opt/babycare && cp server/.env.example server/.env
      # 改 TOKEN_SECRET 和 WEB_PASSCODE
      node server/index.js
      ```
- [ ] 浏览器打开 `http://服务器IP:3000`，输入口令，记一条睡眠 → **网页版可用**
- [ ] 开发者工具导入项目，详情 → 本地设置 → 勾选「不校验合法域名」
- [ ] `miniprogram/config.js` 临时填 `API_BASE: 'http://服务器IP:3000'`
- [ ] 真机预览，走一遍：开始睡觉 → 醒了 → 亲喂 → 统计页

**验收**：手机上能看到今日概览与时间轴，数据在服务器 `data/babycare.db` 里能查到。

> 此时全家已经可以用网页版；小程序还在"开发调试"状态，家人还扫不了码。

### Phase 1 · 本周（半天提交，等 2–3 周）：域名 + 备案

- [ ] 买域名（¥9–19/年，`.top` / `.xyz` 首年最便宜）
- [ ] 完成**域名实名认证**（备案前置条件）
- [ ] 确认服务器在**中国大陆境内**（境外无法备案，见 §6）
- [ ] 在服务器所属云厂商提交 ICP 备案：
      - 主体：个人
      - 网站名称：用中性词（如「个人生活记录」），**不要**出现"宝宝""医疗""健康"等可能被卡的词
      - 备案服务号：境内 ECS/轻量实例购买时长 ≥ 3 个月才给
- [ ] 备案期间：域名暂不解析、80/443 先不通（云厂商会拦，属正常）

**验收**：备案订单进入「管局审核」状态。

### Phase 2 · 备案通过后（1 小时）：切 HTTPS + 上线体验版

- [ ] DNS 解析 `baby.example.com` → 服务器 IP
- [ ] Caddy 反代（自动申请 Let's Encrypt 证书）
      ```
      baby.example.com {
          encode zstd gzip
          reverse_proxy 127.0.0.1:3000
      }
      ```
- [ ] `curl https://baby.example.com/healthz` 返回 ok
- [ ] `miniprogram/config.js` → `API_BASE: 'https://baby.example.com'`（**只填域名，不带路径和端口**）
- [ ] 微信公众平台 → 开发管理 → 开发设置 → 服务器域名 → request 合法域名添加该域名
- [ ] 开发者工具上传代码（填版本号）
- [ ] 公众平台 → 版本管理 → 开发版本 → **「选为体验版」**
- [ ] 成员管理 → 添加家人的微信号为**体验成员**
- [ ] 家人扫码，完整走一遍

**验收**：家人的手机（非开发者账号）能打开并记录，两台设备数据互通。

> ⚠️ **绝对不要点「提交审核」和「发布」。** 一旦发布就要过审、要符合公开运营规范，这不在本方案范围内。

### Phase 3 · 长期

- [ ] `systemctl enable babycare`（开机自启）
- [ ] 每月看一眼 OSS 上有没有当天的快照
- [ ] 每季度做一次恢复演练（`server/restore.js --dry-run`）
- [ ] 每月导出一次 CSV 发到微信文件传输助手

## 4. 体验版专属备忘

| 事项 | 说明 |
| --- | --- |
| 会不会过期 | **不会**。一直有效，直到你上传新版本替换它 |
| 二维码 | 约 7 天失效，**重新生成即可**，版本本身不受影响 |
| 谁能打开 | 只有被加入的**体验成员**；非成员扫码会被拦，也搜不到 |
| 人数上限 | 个人主体约 15 人（家庭够用） |
| 更新版本 | 重新上传 → 再点「选为体验版」；会替换旧版，家人重新打开小程序即生效 |
| 不支持 | 支付、被搜索、分享给非成员、部分开放能力——家庭记录都用不到 |
| 会不会被回收 | 保持账号正常（偶尔登录后台）即可；长期不登录有被限制的风险 |

## 6. 风险与预案

| 风险 | 概率 | 预案 |
| --- | --- | --- |
| 备案被拒 | 中 | 常见原因是网站名称不规范或有经营性表述。改中性名称重新提交，不影响已买域名 |
| 服务器在境外，无法备案 | — | 若为境外机：要么换一台境内轻量服务器（¥35/月），要么停留在网页版方案 |
| 域名被微信判为不安全 | 低 | 换域名重新配置，代码只改 `API_BASE` 一行 |
| 服务器到期/迁移 | 低 | 零依赖，`rsync` 代码 + 拷 `babycare.db`，10 分钟 |
| 数据丢失 | 低 | OSS 每日快照（30 天）+ CSV + `restore.js`，已演练 |
| 微信调整体验版政策 | 低 | 届时直接走「提交审核 → 发布」即可，后端与域名都已就绪，**没有返工** |
| 忘记备份域名/服务器 | 中 | 在日历上设两个提醒：域名到期前 30 天、服务器到期前 30 天 |
