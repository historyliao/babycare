# 宝宝作息（睡眠 / 喝奶）

记录婴儿的**睡眠**（起止、时长、每天总时长）和**喝奶**（亲喂 / 瓶喂母乳 / 配方奶）。

**形态：微信小程序（体验版）。后端：微信云开发。不买域名、不备案、不用服务器。**

| 项 | 情况 |
| --- | --- |
| 月成本 | **¥0**（云开发免费环境，配额 20 万次调用/月，家庭用量约 0.75%） |
| 家人怎么用 | 扫码打开体验版，输入 6 位邀请码加入同一家庭组 |
| 政策窗口 | 云开发免费活动截止 **2026-12-31**，之后的三条退路见 [PLAN.md §7](docs/PLAN.md) |

> ⚠️ **永远不要点「提交审核」和「发布」**。一旦发布，免费环境 15 天后转付费，且需要过审。
> 停在体验版没有任何时间限制（网传的 14 天/30 天限制的是「试用小程序」，不是体验版）。

## 特点

- **抱娃单手可用**：`开始睡觉` → `醒了`，`亲喂·左` → `结束`，两下记完；支持夜间模式。
- **离线可用**：断网也能记，联网自动补传。
- **家庭共享**：邀请码 6 位，多人看同一份数据；数据按家庭组隔离，客户端无法伪造。
- **数据不丢**：云数据库 + 本机缓存 + 每日云端快照(30 天) + CSV 导出。
- **零后端运维**：没有服务器、没有域名、没有证书要管。

## 快速开始

1. 微信开发者工具导入本仓库根目录，填自己的小程序 AppID
2. 工具栏「云开发」→ 开通 → 创建环境 → 复制**环境 ID**，填进 [`miniprogram/config.js`](miniprogram/config.js) 的 `ENV_ID`
3. 右键 [`cloudfunctions/api`](cloudfunctions/api) 和 [`cloudfunctions/backup`](cloudfunctions/backup) → **上传并部署：云端安装依赖**
4. 编译运行 → 验证能记一条 → 上传 → 公众平台「选为体验版」→ 添加家人为体验成员

每步的验收标准见 [docs/PLAN.md](docs/PLAN.md)。

## 数据在哪

| 层 | 位置 | 说明 |
| --- | --- | --- |
| 主存储 | 云开发数据库 `records` | 权威数据，多设备共享 |
| 本机缓存 | 小程序 `wx.setStorageSync` | 离线记录、秒开 |
| 云端快照 | 云存储 `backups/YYYY-MM-DD/*.json` | 定时 03:30 生成；免费环境的定时器不可靠时，打开小程序会兜底补一条；保留 30 天 |
| 离机留存 | 设置页导出 CSV | 自己保存一份，可导入 Excel |

删除是**软删除**（`deleted: true`），误删可在云开发控制台把该字段改回 `false` 并更新 `updatedAt` 找回。
